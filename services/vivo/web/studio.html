Physical dimensions and camera views are different controls

The upper 2D–9D buttons choose the number of independent spatial axes used in distance, motion, spring forces, soft contacts, and field coupling. Time is separate. Selecting a different dimensional law creates a child branch, keeping up to twelve parent checkpoints in this session. The smaller CAMERA ONLY buttons change the projection without changing the simulation. A 4D spatial model plus its clock is not ordinary 3+1-dimensional spacetime.

Coordinates outside the active dimension are retained but dormant. Switching laws resets bonds to seven-nearest-neighbor geometry in the active metric and establishes a new energy baseline; it does not preserve the old branch's trajectories or promise equal energy across different laws. Use “Return to parent checkpoint” to restore the parent exactly.

Field shows interpolated samples around connections. Network exposes the actual connections. Memory colors activity by its leaky memory trace. Landmark names are annotations, not automatically discovered concepts.

What “adaptive” means here

Local plasticity slowly adjusts bounded connection weights using node co-activation. That is an implemented update rule, not evidence of useful intelligence. The separate forecasting experiment trains a linear readout and reports a chronological holdout error against a persistence baseline.

What is not built yet

No general relativity, quantum field theory, real chemistry, continuum-PDE convergence proof, general-purpose agents, language model, trained cellular automaton, living avatars, external data integrations, headset VR, persistent AR anchors, multiplayer, emergent object discovery, or security-grade ledger. The field does not know things about the outside world.

Research directions

Signal processing on graphs is a foundation for thinking about signals on irregular networks. Growing Neural Cellular Automata demonstrates trained local rules that grow and regenerate patterns. These are reading directions, not claims that this prototype reproduces those results.

The core application makes no network requests. Camera-only video requires permission but no model download. Front + hands and Back + hands explicitly start both video and model loading. Explicitly enabling head or hand tracking downloads MediaPipe assets from jsDelivr and Google Storage; the providers receive ordinary download metadata. Frames are processed locally by this code, not uploaded; Studio can explicitly record locally. Stop, Escape, closing the camera panel, and hiding the tab release camera tracks. Physical-camera tracking is experimental and needs device testing. Research links open only when selected. JSON imports are bounded and validated; do not store secrets in a field file.

The dimensions do the work.

2–9 independent spatial coordinates, plus one simulation clock. All active axes enter pair distances, movement, soft contact, bond lengths, and an oscillator coupling that changes with bond strain. Field pressure feeds back into motion.

Try the ninth axis

Close this panel, select 9D above, select “x9” in the inspector and press “Kick along axis”. Resume the world. The actual x9 coordinate changes. “All axes” projects this movement; “3D” hides it without removing its physical effects.

Energy is measured, not implied by brightness

Energy includes mechanical and scalar kinetic energy, nonlinear oscillator potential, spring potential, strain-dependent field coupling, and soft-contact potential. Bath loss counts energy removed by explicit damping. Residual = current energy − starting energy − supplied work + bath loss. Small residuals are numerical error, not entropy or a new energy source. Damping and plasticity are open-system controls, not closed-system conservation.

Scope

This is a classical finite spring/oscillator network with unit masses and arbitrary model units. It is not a continuum simulation, relativistic solver, quantum universe, organism or demonstration of extra physical dimensions. Soft contacts are repulsive potentials, not a guarantee of non-penetration. The separate learning benchmark is unchanged and does not train this moving network.

Current branch

Parents remain as session checkpoints only, up to twelve. JSON exports preserve the current branch and its parent identifier, not the whole tree. Loading a file clears the session parent stack. Changing a view never changes a branch.

Research basis and boundaries

MIT: wave equations in n dimensions supplies the continuum mathematical context; this code instead evolves a finite graph. CERN: extra dimensions explains the physical hypothesis, not an experimental confirmation. Complete equations and reproducible code tests are in the source package.
