Controls

Tap an object, then drag it. A gold handle means the server accepted your grab. Touch and hand input use the same ownership rules.

Flat spaces: full-dimensional ball contacts. Curved spaces: chart-local handles with metric/geodesic movement; solid curved-body collision is not implemented.

The Eye belongs to you. Changing it does not change your collaborator’s viewpoint.

0

Drag empty space to orbit, pinch or scroll to zoom. Observer axes are explicit. Overview ghosts are a map, not full-dimensional eyesight.

Camera overlay, not world-anchored AR. Live hand recognition runs locally in a worker. No camera frames are sent to collaborators.

OFF

Show an open hand first, point, then pinch and move. Missing/stale hands release the object. Darkness does not create usable sensor information. Touch stays available. Eye means observer navigation, not calibrated eye tracking.

A room that responds locally

The trained rule estimates movement cost. Neighbor-to-neighbor updates grow a guidance field toward a goal. Blocking a cell forces the field to rebuild.

369 trained parameters, synthetic task, pinned model. Local organization is emergent from repeated updates; no general intelligence, free-form room generation or online retraining is claimed. No rule moves your work without an edit.

Links are bearer capabilities. Anyone with the link can use its role. HTTPS protects transport; the server can read shared object state. This is not end-to-end encryption.
