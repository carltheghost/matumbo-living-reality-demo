## Fixed design

- Optimizer and budget: the existing Adam-style update, existing learning rate and gradient clip, exactly `1000` updates per trial, fixed optimizer seed `model_seed + 1000`, four trials, and a cooperative `300`-second CPU wall-clock cap.

## Controlled architecture change

The candidate selects `shared_row_scorer` while the legacy baseline selects
`legacy_action_matrix`. Only the final action head changes.

For each current response row (r_i) and retained context (c), the candidate
uses one shared bilinear scorer:

```text
score_i = r_i · W_shared_row_context · c + r_i · w_shared_row + b_shared_row
```

The full model retains a pre-final central state plus memory read (`18` context
features); the control retains a pre-final hidden state plus memory read (`51`
features). The response matrix is represented as four rows of four features.
There is no per-gate bias or embedding, and the same row-scoring weights apply
to every physical row. Parameter counts are expected to change only from
`11183 → 11184` for the full model and `11178 → 11179` for the control.

The shared gate and frequency heads use the retained pre-final context. The
final post-response recurrent state is still computed by the body but is not
used by these shared action heads. This makes the final response-row
permutation test well-defined while avoiding a claim about whole-trajectory
slot causality.

Frequency/goal information may be carried by the recurrent retained state from
the note and delay; no evaluator target, reference gate, or frequency label is
provided to inference. The current shared gate receives the current response
rows, not an injected frequency index. No phase or time signal is synthesized:
magnitude-only response measurements remain magnitude-only.

1. gradient routing through `W_shared_row_context` and `w_shared_row`;
2. row-permutation probability/selection parity with exact-tie handling;
3. serialization and exact prediction parity;
4. rejection of legacy normalization for the shared head;
5. preprocessing/context row-symmetry audits;
6. frozen diagnostics of training-world maps/confusions, model agreement,
   confidence/margins, success-set overlap, and the inspected development
   cases; and
7. preservation of historical reports/checkpoints byte-for-byte.

The diagnostic's structural shared-head replay is untrained and is not
performance evidence. It only verifies the controlled head's symmetry.
