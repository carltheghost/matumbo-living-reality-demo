## New code boundary

The physics, five-brain model, addressable memory, event store, exact note
workspace, tool boundary and proof runner are a clean NumPy-based
reconstruction. No prior source file is copied into the package. The
mathematical edge terms are included because they are part of the delegated
architecture contract and are independently tested here.

No Obsidian code or other third-party application code is included. NumPy is
used as an installed numerical dependency and SQLite/FTS5 comes from Python's
standard library/system SQLite; their source is not vendored. The parent task
researched but did not select a larger notes application or editor dependency.

## Claims deliberately not made

The proof does not establish a universal agent, consciousness, world-best
performance, a real physical device, general web/tool access, production
safety, or that code can be baked into weights with universal ability. Exact
documents, permissions and execution remain deterministic state/code.
